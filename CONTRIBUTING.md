# Contributing Guidelines

Thank you for your interest in contributing to the Distributed Job Scheduler!

## Getting Started

1. Fork the repository and clone it locally.
2. Ensure you have Docker and Docker Compose installed.
3. Install backend dependencies using a virtual environment and frontend dependencies with `npm install`.

## Code Style

- **Python**: Follow PEP 8 guidelines. Code formatting is enforced via `black` and `isort`.
- **TypeScript/React**: Follow standard ESLint rules. Code style is formatted via `prettier`.

## Submitting Pull Requests

1. Create a descriptive feature/bug branch from `master` or `main`.
2. Commit your changes with clear, structured messages.
3. Write test cases for your features under `backend/tests/`.
4. Ensure all CI pipeline checks pass.
5. Submit the PR using our Pull Request Template.
