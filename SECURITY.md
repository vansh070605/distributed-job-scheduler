# Security Policy

## Supported Versions

Only the latest release version is supported.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of the Distributed Job Scheduler seriously. If you find any vulnerabilities, please do not open a public issue. Instead, report them directly by emailing the maintainer at `vansh.agrawal.contact@gmail.com`.

We will respond within 48 hours to confirm receipt and provide a timeline for addressing the issue.
